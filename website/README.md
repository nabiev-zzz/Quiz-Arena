# QUIZ ARENA official landing page

A lightweight, responsive, static product website in Uzbek, Russian and English.

## Preview locally

Open `index.html` in a browser, or run a simple static server from the repository root:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080/website/`.

## Publish

This folder is self-contained and can be deployed to any static hosting provider (GitHub Pages, Cloudflare Pages, Netlify or Vercel).

- Build command: none
- Output / publish directory: `website`
- No environment variables or backend required.

The site reuses the app icon from `../assets/`. Store buttons intentionally remain disabled until official Android and iOS distribution URLs are available. Do not replace them with guessed APK or store links.

## Content

- Responsive landing page and app preview
- Uzbek, Russian and English language switcher
- Feature overview, how-it-works section and subscription prices
- Download section with clearly marked coming-soon buttons
